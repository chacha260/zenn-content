## はじめに

ポモドーロタイマー、作業用 BGM、タスク管理を、Obsidian のサイドパネルひとつにまとめるプラグイン「Zen Zone」を作りました。

https://github.com/chacha260/obsidian-zen-zone

![Zen Zone の画面](https://github.com/user-attachments/assets/2c1a4b1e-fb70-4433-9f1f-45f36c0506d7 =484x)

できることは 3 つです。

- **ポモドーロタイマー**:集中と休憩を自動で切り替える
- **BGM**:YouTube か、保管庫内の音声ファイルを流す
- **タスク**:いま取り組むタスクを置き、デイリーノートに記録する

タイマーが切り替わるたびに BGM も切り替わるので、「集中のときはこの曲、休憩のときはこの曲」を一度決めれば、あとは開始ボタンを押すだけです。

きっかけは職場の環境です。社内の PC は操作ログが記録されていて、ブラウザで YouTube を開いておくのは、どうにも気が引けます。

それでも、YouTube の作業用 BGM や YouTube Music のプレイリストを流しながら作業したい。それなら、いつも開いている Obsidian の中で完結させてしまおう、というのが出発点です。

開発には Anthropic の Claude Code を使いました。設計の相談から実装、コミュニティプラグインへの申請対応まで、対話しながら進めています。

## インストール

Obsidian 1.13.0 以降が必要です。デスクトップとモバイルの両方で動きます。

**設定 → コミュニティプラグイン → 閲覧** で「Zen Zone」を検索し、インストールして有効化します。

有効にしたら、リボンの ⚡ アイコンでパネルが開きます。

## タイマー

![Zen Zone の画面](https://github.com/user-attachments/assets/3bcabce5-46ee-4855-a480-b386ee00e2c2 =466x)

「集中を開始」を押すと、集中 → 小休憩 → 集中 → … と進み、最後のサイクルは大休憩で終わります。

- **進み具合がひと目で分かる**:残り時間のまわりのリングが減っていき、サイクルは点(●●○○)で表示されます。
- **回数も時間も自由**:サイクル数は 1〜12 回、集中は 1〜180 分の範囲で設定できます。25 分・5 分に縛られません。
- **自分のペースで**:休憩や次の集中を自動で始めるか、操作を待つかを選べます。途中でスキップもできます。
- **パネルを閉じても止まらない**:残り時間はステータスバーに出続けます。ステータスバーをクリックすると、一時停止・スキップ・音楽の操作ができるメニューが開きます。
- **スリープしてもずれない**:終了時刻を基準に数えているので、PC がスリープから復帰しても正しい残り時間になります。
- **気づける**:Obsidian が裏に回っているときは、フェーズの切り替わりをシステム通知で知らせます。

集中中はサイドバーを閉じたり、リボンやタブの見出しを隠したりする設定もあります。閉じたサイドバーは、終わると元に戻ります。

完了した集中の回数と時間は日ごとに記録され、タイマーの下に今日の合計と直近 7 日間の棒グラフが出ます。

## BGM

![Zen Zone の画面](https://github.com/user-attachments/assets/0818562a-996a-4994-93a3-e654237bc4ee =458x)

トラックには 2 種類を登録できます。

- **YouTube の動画・プレイリスト**:URL を貼るだけです。YouTube Music のプレイリストの URL も使えます。ただし、埋め込み再生が許可されていない曲は流れないため、プレイリストによっては再生できないものがあります。
- **保管庫内の音声ファイル・フォルダ**:フォルダを指定すると、中の音声ファイルがプレイリストになります。オフラインでも使えます。

操作は、再生/一時停止・前後の曲・シャッフル・リピート(オフ/全曲/1 曲)・音量です。設定は記憶され、パネルを閉じても音楽は流れ続けます。

### サイクルごとに曲を変える

設定の「サイクルごとの音楽」で、各サイクルの集中用と休憩用のトラックを選べます。

たとえば、1〜3 サイクル目の集中は Lo-fi、最後だけ別の曲、休憩は雨音、といった組み合わせができます。タイマーが切り替わると、BGM も自動で切り替わります。

### チェックポイント

長い動画には、時刻に名前を付けておけます。「朝」「夜」のように登録しておくと、パネルのボタンひとつでその位置へ飛べます。

### 切り替え時の効果音

フェーズが変わる瞬間に、保管庫内の音声ファイルを鳴らせます。効果音のあいだ BGM を何秒待たせるかも指定できます。

### YouTube を使うときの注意

:::message
- YouTube のトラックは、YouTube の埋め込みプレイヤーで再生しています。再生を始めるまで通信は行いません。
- 再生中は、通常の埋め込み動画と同じ情報(IP アドレス、再生している動画など)が YouTube に送られます。広告が流れることもあります。
- 既定では、画面の隅に小さなプレイヤーが表示されます。設定で非表示にできますが、YouTube の利用規約は埋め込みプレイヤーを見える状態で使うことを求めています。
- プラグイン自体は、利用状況の収集などの通信を一切行いません。
- Obsidian の中で再生していても、YouTube との通信そのものは発生し、ネットワークの記録には残ります。職場で使う場合は、勤務先のルールに従ってください。
:::

通信を一切させたくない場合は、保管庫内の音声ファイルだけで使えます。

## タスク

![Zen Zone の画面](https://github.com/user-attachments/assets/238a4bb8-2431-4533-a146-93e4b221c5a1 =473x)

パネルの上に「現在のタスク」がひとつ表示され、その下にバックログが並びます。

- **見積もりと実績**:タスクに予定ポモドーロ数を付けると、`🍅2/4` のように進み具合が出ます。見積もりを超えると色が変わります。
- **切り替え**:バックログのタスク名をクリックすると、それが現在のタスクになります。
- **編集と取り消し**:タスク名と見積もりは後から直せます。完了や削除は、直後の通知から取り消せます。
- **今日やったこと**:完了したタスクは、時刻つきで「今日完了したタスク」に残ります。

### デイリーノートとの連携

設定で有効にすると、タスクがデイリーノートに記録されます。

タスクを追加すると、今日のノートの見出しの下にチェックボックスが入ります。

```markdown
## Todo
- [ ] 報告書を書く
```

完了すると、時刻とポモドーロ数が付きます。

```markdown
## Todo
- [x] 14:35 報告書を書く 🍅3/4
```

さらに、集中を 1 回終えるたびにログを残すこともできます。

```markdown
## Focus log
- 13:00–13:25 🍅 報告書を書く
- 13:30–13:55 🍅 報告書を書く
```

一日の終わりにデイリーノートを開けば、何にどれだけ時間を使ったかがそのまま残っています。

ほかにも次のことができます。

- **取り込み**:デイリーノートに手で書いた未完了のチェックボックスを、タスクとして取り込めます。
- **持ち越し**:前日に終わらなかったタスクを、ボタンひとつで今日のノートへ移せます。元のノートの行は `- [>]`(持ち越し済み)に変わります。
- **テンプレート**:デイリーノートがまだない日は、コアプラグイン「デイリーノート」のテンプレートを使って作成します。

## コマンド

パネルを開かなくても、コマンドパレットから操作できます。ホットキーは初期状態では割り当てていないので、**設定 → ホットキー** で好きなキーを設定してください。

| コマンド | 動作 |
|:---|:---|
| パネルを開く | サイドパネルを開く |
| 集中タイマーを開始/一時停止 | セッションの開始・一時停止・再開 |
| 次のフェーズへスキップ | いまのフェーズを切り上げる |
| 集中セッションをリセット | 最初のサイクルに戻す |
| 音楽を再生/一時停止 | 再生の切り替え |
| 次のトラックを再生 | プレイリストやフォルダの次の曲へ |

表示言語は Obsidian の設定に従い、日本語と英語に対応しています。

## 使い方の例

一日の流れは、たとえばこうなります。

1. 朝、デイリーノートに今日やることをチェックボックスで書く。
2. Zen Zone のパネルで取り込みボタンを押し、それぞれに見積もりを付ける。
3. 最初のタスクをクリックして「集中を開始」。
4. あとはタイマーと BGM に任せて作業する。終わったタスクにチェックを入れる。
5. 一日の終わりに、デイリーノートで見積もりと実績を見比べる。

## おわりに

「タイマー」「BGM」「タスク」はそれぞれ優れたアプリやプラグインがありますが、切り替えのたびに集中が途切れるのが気になっていました。Zen Zone は、その行き来をなくすためのプラグインです。
